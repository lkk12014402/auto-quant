## Model Details

This model is an MXFP8 (W8A8, group_size 32) model of [nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16) generated by [intel/auto-round](https://github.com/intel/auto-round) using RTN. Please follow the license of the original model.

- **Quantized (MXFP8)**: routed experts, shared experts, Mamba projections
- **Kept in BF16**: attention, router, Mamba conv1d, Mamba projections adjacent to attention, embeddings, lm_head
- **Static FP8**: KV cache, attention

## How to Use

### Environment

```bash
uv pip install vllm==0.31.0
```

### vLLM Usage

```bash
vllm serve INCModel4/NVIDIA-Nemotron-3-Nano-30B-A3B-MXFP8-FP8KV-FP8Attn-CT-RTN-AutoRound \
    --tokenizer nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16 \
    --moe-backend humming \
    --attention-backend TRITON_ATTN \
    --dtype bfloat16 \
    --kv-cache-dtype fp8
```

## Generate the Model

```bash
AR_DISABLE_META_LOAD=1 auto-round \
    --model_name nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16 \
    --scheme MXFP8 \
    --algorithm rtn \
    --iters 0 \
    --static_kv_dtype fp8 \
    --static_attention_dtype fp8 \
    --ignore_layers lm_head,backbone.embeddings,mixer.q_proj,mixer.k_proj,mixer.v_proj,mixer.o_proj,mixer.gate,mixer.conv1d,model.layers.4.mixer.in_proj,model.layers.4.mixer.out_proj,model.layers.11.mixer.in_proj,model.layers.11.mixer.out_proj,model.layers.18.mixer.in_proj,model.layers.18.mixer.out_proj,model.layers.25.mixer.in_proj,model.layers.25.mixer.out_proj,model.layers.32.mixer.in_proj,model.layers.32.mixer.out_proj,model.layers.41.mixer.in_proj,model.layers.41.mixer.out_proj \
    --format llm_compressor \
    --seqlen 2048 \
    --batch_size 1 \
    --nsamples 128 \
    --disable_trust_remote_code \
    --output_dir NVIDIA-Nemotron-3-Nano-30B-A3B-MXFP8-FP8KV-FP8Attn-CT-RTN-AutoRound
```
