## Model Details

This model is an MXFP8 (W8A8, group_size 32) model of [google/gemma-4-31B](https://huggingface.co/google/gemma-4-31B) generated by [intel/auto-round](https://github.com/intel/auto-round) with 200 tuning iterations. Please follow the license of the original model.

- **Quantized (MXFP8)**: attention, MLP
- **Kept in BF16**: embeddings, vision tower, vision projection
- **Static FP8**: KV cache

## Generate the Model

```bash
uv pip install git+https://github.com/intel/auto-round.git@20710256296c4e129de5ef9639755bc8a03edcbe
```

```bash
auto-round \
    --model_name google/gemma-4-31B \
    --scheme MXFP8 \
    --algorithm auto_round \
    --iters 200 \
    --nsamples 128 \
    --static_kv_dtype fp8 \
    --ignore_layers embed_tokens,vision_tower,embed_vision \
    --format llm_compressor \
    --output_dir gemma-4-31B-MXFP8-FP8KV-CT-AutoRound
```
